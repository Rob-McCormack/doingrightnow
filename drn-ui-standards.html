UI standards

Doing Right Now, and the other apps that should feel the same.

Open this file in a browser and use the samples. The sentence under each heading is the rule. A later pass checks DoingRightNow.html against this page.

Color and type

One green, one danger red, one muted gray. Text is 16px, rounded system type. Focus is a 3px green outline, never a glow.

Green Page Panel Muted Danger

Buttons

Primary does the main action. Secondary is the quiet alternative. Danger removes something. Icon buttons are 42px, muted until hovered. Disabled buttons fade and do not look clickable.

Toast

One toast, bottom center. It confirms something that already happened, or reports a failure that does not need a decision. It stays for 6 seconds and can be dismissed. A new toast replaces the old one. If a dialog is open when the time runs out, the toast waits until the dialog closes.

Also used for “Logged at …”, “Entry deleted”, “Timezone saved”, “Preferences reset”, “Markdown copy downloaded”, and import results.

Dialogs

Use a dialog when the person must read or decide. Title at the left, close icon at the right. A short green label may sit above the title. Cancel is secondary. The confirming button is primary and sits at the end. A destructive button is danger and sits at the start. Escape or a click on the dimmed backdrop closes it. The dialog stays until the person closes it.

Copy

Success changes the button itself: a check, then the word Copied, for 1.6 seconds. Then it returns to Copy. No toast for success. Failure uses the toast “Could not copy.”

Errors and quiet notes

A problem the person must fix is an inline message, in the dialog or at the top of the page. It is not a toast. Quiet explanation is smaller muted text, not a notification.
