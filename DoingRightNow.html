About the app

Version 1.0.0-beta.1

A private, local-first journal for getting unstuck—one timestamped line at a time.

doingrightnow.com

Navigation and entry actions

Use the hamburger to open the navigation drawer. Tap the current view title to return directly to Today; when already on Today, it scrolls to the top without opening the keyboard. The right side keeps only the command icon, which offers the same destinations from a searchable palette.

Quick start

  • Write the smallest thing you are doing in the Today box.
  • Press Enter or the + button to timestamp it.
  • Write another line whenever your focus changes.

Command palette

Press ⌘K or Ctrl+K, or use the command icon. The palette includes adding an activity; every journal view; Search; Quick Note; Zen mode; Settings; System backup tools; Help; appearance; and temporary Developer tools. Type to filter, then use Enter or the arrow keys to choose.

Quick Note

Tap the accent-colored Quick Note control or its chevron below the Doing Right Now card to disclose a reusable note. The chevron rotates to show whether the note is open. It saves automatically as you type. Use its small Copy button to place the note on your clipboard. The Command Palette can open and focus Quick Note directly.

Quick Add and formatting

Use the lightning button for reusable entries. Type @ for people, + for projects, or # for places. Suggestions come only from the corresponding lists in Settings. Add standalone ^ for started, ! for important, or ? for a question. Wrap text in backticks, such as `next step`, to display it in monospace.

Timer, time, and date

The timer is enabled by default, but it is optional. It shows how long the newest Today entry has been current. Its animated timer icon has a second hand that circles every minute to show passing time, not a target. If the timer feels distracting or creates pressure, turn off Timer on current entry in Settings; the journal works exactly the same without it. The numeric elapsed-time counter is a duration, so it does not use AM/PM. Settings also lets you choose 12-hour or 24-hour clock timestamps, Regional or numeric date formats, and Small, Medium, or Large text.

Zen mode

Use the Expand icon at the upper right of the current Doing Right Now card to enter Zen mode. Clicking anywhere else in that card edits the current entry. Zen mode repeats the display in a distraction-free full-screen view. The clock, formatting, and complete current entry remain visible; the stopwatch and elapsed time follow the Timer setting.

Appearance

Settings provides Green, Blue, Violet, Amber, Coral, and Pumpkin accent colors. The app icon always remains green. Accent color works independently from the System, Light, and Dark appearance button. The green Doing Right Now label uses a subtle left-to-right shimmer, which is disabled when reduced motion is preferred.

Day ratings, counts, and trophies

Ratings are available for Yesterday and earlier days; Today cannot be rated. In history views, tap a past day heading to cycle its rating from zero to five stars. Each heading shows started entries compared with total entries. A trophy appears when the total reaches the threshold configured in Settings. Plain-text copies show ratings as * characters.

Links

When an entry contains an http://, https://, or www. address, both its editing popup and ellipsis action sheet list the link so you can open it directly. Opening a link closes the popup and leaves you at the entry.

Edit and find entries

Entries can contain up to 1,000 characters. The dialog editor supports multiple lines and shows a live character count. Press Enter to save or Shift+Enter for a new line. Long entries are shortened to three lines in the current card and two lines in journal lists; tap one to view and edit its complete text. Search starts empty; type a word, phrase, or tag such as @person, +project, or #place to see matches.

Import confirmation

Import reads a Doing Right Now JSON backup, shows its entry count and date range, and asks for confirmation before replacing the current journal, Quick Note, lists, ratings, and settings.

Privacy and security

Your journal is stored in IndexedDB in this browser and is not sent to an account or cloud service. Anyone with access to this browser profile may be able to read it. Export a backup before clearing browser data or changing devices.

Your data

Tabs and windows in the same browser synchronize automatically; other browsers and devices remain separate. System → Data & backup shows storage and backup information. Cleanup keeps your Quick Note, lists, and settings. Reset clears app data and restores starter lists.
