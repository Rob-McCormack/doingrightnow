About the app

Version 1.0.0-beta.1

A private, local-first journal for getting unstuck—one timestamped line at a time.

doingrightnow.com

Navigation and entry actions

Use the hamburger to open the navigation drawer. Tap the current view title to return directly to Today; when already on Today, it scrolls to the top without opening the keyboard. The right side keeps the command icon and Quick Note. The command palette offers the same destinations from a searchable list.

Quick start

  • A new journal begins with one normal entry: Trying out Doing Right Now. You can edit or delete it.
  • Write the smallest thing you are doing in the Today box.
  • Press Enter or the Enter-icon button to timestamp it.
  • Write another line whenever your focus changes. The two brief onboarding messages do not return after your first entry.

Command palette

Press ⌘K or Ctrl+K, or use the command icon. Choose in any of three ways: type a more specific phrase and press Enter, click or tap a command, or use the arrow keys and Enter. For example, instead of stopping at project, search for open document, new project, or search documents. Add an activity and Go to Today stay first; the rest are alphabetical. Settings commands are prefixed Settings:, System commands System:, project commands Project:, and issue commands Issue:. Document and issue commands use the last opened project (default +Ongoing) — they do not ask which project. The hint shows the name, such as +Ongoing. GitHub Backup commands appear only when Advanced is on.

Quick Note

Tap the note icon in the header, to the right of the command palette, from any view. It opens a reusable scratchpad that saves automatically as you type. Use its Copy button to place the note on your clipboard. The command palette can open and focus Quick Note directly.

Projects

Optional. Open Projects from the menu. Every journal has +Ongoing — a catch-all document and issue list that cannot be removed. Projects are things you work on. Issues belong to a project. Both are just freeform text — do things your way. Add another project only if you need a separate document.

Today: may be the complete feature. It answers the one cross-project question that fits Doing Right Now: What deserves my attention now?

  1. Add Today: to the beginning of a line in a project document or issue.
  2. It appears in Today across projects, opened with the calendar-check icon.
  3. Open it and work.
  4. Remove Today: when it no longer needs attention.

That is not a status system. The project text remains; only its temporary visibility changes. Tap a collected result to open and select its source line. To find any other project text, use Project: Search documents & issues in the command palette. It searches matching lines in both kinds of text; the regular Search view remains journal-only. Type +Ongoing.1 in a journal line to point at an issue. There are no status fields, assignees, or due dates. Each issue shows a relative time such as 1 hr ago. Longer examples live in Full Help.

Quick Add and formatting

Use the lightning button for reusable entries. Type @ for people, + for projects, or # for places. Suggestions come from the corresponding lists in Settings. Type +Ongoing. (or ongoing.) to list that project’s issues, such as Ongoing.1. Add one standalone special marker: ^ for started, " for a completed small step, ! for important, or ? for a question. Choosing another replaces the current special marker. Wrap text in backticks, such as `next step`, to display it in monospace.

Timer, time, and date

The timer is enabled by default, but it is optional. On Today, it appears under the newest entry’s timestamp: the animated timer icon, then the elapsed time. Its second hand circles every minute to show passing time, not a target. If the timer feels distracting or creates pressure, turn off Timer on current entry in Settings; the journal works exactly the same without it. The numeric elapsed-time counter is a duration, so it does not use AM/PM. Settings also lets you choose 12-hour or 24-hour clock timestamps, Regional or numeric date formats, Small, Medium, or Large text, and Loose or Tight item spacing. Loose is the default.

Zen mode

Use the Expand icon at the upper right of Today’s current entry to enter Zen mode. Tap the entry text to edit it, just like any other line. Zen mode repeats the display in a distraction-free full-screen view. Started, completed, important, and question markers appear as their icons instead of punctuation. The clock, formatting, and complete current entry remain visible; the stopwatch and elapsed time follow the Timer setting.

Appearance

Settings provides Green, Blue, Violet, Amber, Coral, and Pumpkin accent colors. The app icon always remains green. Accent color works independently from the System, Light, and Dark appearance button. Zen mode’s Doing right now label uses a subtle left-to-right shimmer, which is disabled when reduced motion is preferred.

Day ratings, counts, and trophies

Ratings are available for Yesterday and earlier days; Today cannot be rated. In history views, tap a past day heading to cycle its rating from zero to five stars. Each heading shows started entries compared with total entries. A trophy appears when the total reaches the threshold configured in Settings. Plain-text copies show ratings as * characters.

Links

When an entry contains an http://, https://, or www. address, both its editing popup and ellipsis action sheet list the link so you can open it directly. Opening a web address closes the popup and leaves you at the entry. The same list includes +Ongoing or +Ongoing.1 when that project or issue exists; tapping one opens it.

Edit and find entries

Entries can contain up to 1,000 characters. The dialog editor supports multiple lines and shows a live character count. Press Enter to save or Shift+Enter for a new line. The browser’s native spell checker is enabled in the Today composer, entry editor, Quick Note, project documents, issues, and editable copy dialog. Its languages and suggestions come from your browser or device; Doing Right Now does not send text anywhere. Long entries are shortened to three lines with an ellipsis in the journal display; tap one to view and edit its complete text. Search starts empty; type a word, phrase, or tag such as @person, +project, or #place to see matches.

Import confirmation

Import reads a Doing Right Now JSON backup, shows its entry count and date range, and asks for confirmation before replacing the current journal, Quick Note, lists, ratings, settings, project documents, and issues. GitHub connection details and the token stay on this device.

Privacy and security

Your journal is stored in IndexedDB in this browser. There is no Doing Right Now account. Anyone with access to this browser profile may be able to read it. Export a backup before clearing browser data or changing devices. The journal leaves this browser only when you export, copy text, or use optional GitHub Backup.

Your data

Tabs and windows in the same browser synchronize automatically; other browsers and devices remain separate. System → Data & backup shows storage and backup information. Export journal downloads a JSON backup you can restore. Export as text and Export as Markdown download readable copies that cannot be imported. Cleanup keeps your Quick Note, lists, settings, and projects. Reset clears app data, including any GitHub token, and restores starter lists.

Advanced and GitHub Backup

Settings includes an Advanced switch, off by default. Turn it on to show GitHub Backup in System. That uploads the same JSON as Export journal, plus a Markdown copy, to a private repository you control. The token is stored only on this device and is never written into the backup files. GitHub Backup is not sync: this journal stays local, and a failed upload never blocks saving. Restore by downloading backup.json from GitHub and using Import journal. DoingRightNow.md is for reading. Token setup is in Full Help.
